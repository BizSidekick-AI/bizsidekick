# Security

Do not open a public issue for a suspected credential exposure, authorization bypass, unsafe
mutation path, or other vulnerability that could put a Bustly user or connected provider at risk.

Report security issues privately through
[GitHub Private Vulnerability Reporting](https://github.com/BizSidekick-AI/bizsidekick/security/advisories/new).
Include the affected plugin version, client, reproduction steps, and expected safety boundary.
Do not include live credentials or unrelated merchant data.

This repository contains public client distribution assets only. Authentication, authorization,
provider access, mutation enforcement, idempotency, and audit storage are implemented by the
hosted Bustly service and are not part of this repository.
