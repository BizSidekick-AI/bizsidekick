# BizSidekick

[ภาษาที่รองรับทั้งหมด](README.md) · [English](../../README.md)

มาร์เก็ตเพลสปลั๊กอินสาธารณะสำหรับใช้งาน BizSidekick กับ Codex และ Claude ปลั๊กอินเชื่อมต่อกับบริการ
Bustly MCP ที่โฮสต์อยู่ที่ `https://mcp.bustly.ai/mcp` โดยรีโพซิทอรีนี้ไม่มีข้อมูลรับรองของผู้ให้บริการ
ข้อมูลผู้ค้า ซอร์สโค้ดของบริการ MCP หรือข้อมูลลับสำหรับการปรับใช้

## Codex บนเดสก์ท็อป

วางข้อความต่อไปนี้ลงในงานของ Codex บนเดสก์ท็อป:

```text
ใช้ marketplace ปลั๊กอินแบบกำหนดเองของ Codex เพื่อเพิ่ม `BizSidekick-AI/bizsidekick` และติดตั้ง BizSidekick เฉพาะเมื่อจำเป็น อย่าเปิดหรืออ่าน repository ในเบราว์เซอร์ ใช้สถานะการเข้าสู่ระบบเดิมของฉัน หากการอนุญาตเสร็จสมบูรณ์โดยไม่ต้องตั้งค่าบัญชี ให้ตรวจสอบการเชื่อมต่อแล้วสร้างและเปิดงาน BizSidekick ใหม่เพียงหนึ่งงานโดยอัตโนมัติเพื่อแสดงร้านค้าและสินค้าล่าสุดของฉัน หากต้องเข้าสู่ระบบ สมัครบัญชี หรือทำ onboarding ของ BizSidekick ให้เปิดงานติดตั้งนี้ไว้ ขอให้ฉันดำเนินการในเบราว์เซอร์ให้เสร็จและตอบ `ดำเนินการต่อ` จากนั้นตรวจสอบการอนุญาตและสร้างงาน
```

วิธีสำรองผ่าน CLI:

```bash
codex plugin marketplace add BizSidekick-AI/bizsidekick --ref main
codex plugin add bizsidekick@bizsidekick
codex mcp login bizsidekick
```

## Claude Code

วางข้อความต่อไปนี้ลงใน session ของ Claude Code:

```text
ใช้ marketplace ปลั๊กอินแบบกำหนดเองของ Claude Code เพื่อเพิ่ม `BizSidekick-AI/bizsidekick` และติดตั้ง `bizsidekick@bizsidekick` เฉพาะเมื่อจำเป็น อย่าเปิดหรืออ่าน repository ในเบราว์เซอร์ รักษาสถานะการเข้าสู่ระบบเดิมของฉันไว้ และเรียก `/reload-plugins` เพียงหนึ่งครั้งหลังการติดตั้งใหม่ หากการอนุญาตเสร็จสมบูรณ์โดยไม่ต้องตั้งค่าบัญชี ให้ทำต่อใน session นี้และเริ่มงาน BizSidekick แบบอ่านอย่างเดียวโดยอัตโนมัติเพื่อแสดงร้านค้าและสินค้าล่าสุดของฉัน หากต้องเข้าสู่ระบบ สมัครบัญชี หรือทำ onboarding ของ BizSidekick ให้เปิด session นี้ไว้ ขอให้ฉันดำเนินการในเบราว์เซอร์ให้เสร็จและตอบ `ดำเนินการต่อ` จากนั้นตรวจสอบการอนุญาตและเริ่มงาน
```

วิธีสำรองผ่าน CLI:

```bash
claude plugin marketplace add BizSidekick-AI/bizsidekick
claude plugin install bizsidekick@bizsidekick --scope user
```

## รูปแบบการรักษาความปลอดภัย

- การเข้าสู่ระบบ Google/Bustly ดำเนินการในเบราว์เซอร์ผ่าน OAuth ส่วนการเลือกพื้นที่ทำงานจะเกิดขึ้นภายในงานทางธุรกิจ
- สิทธิ์ OAuth ที่จำกัดตามผู้ใช้จะถูกจำกัดด้วยการเป็นสมาชิก Bustly ในปัจจุบัน โดยหนึ่งงานจะผูกกับพื้นที่ทำงานเพียงหนึ่งแห่งเท่านั้น
- การอ่านโดยไม่ระบุร้านค้าจะครอบคลุมการเชื่อมต่อทั้งหมดที่ใช้งานอยู่และเข้าถึงได้ในพื้นที่ทำงานนั้น และไม่ต้องมีการยืนยัน
- การเปลี่ยนแปลงจะแสดงตัวอย่างก่อน และจะนำไปใช้หลังจากได้รับการอนุมัติอย่างชัดเจนเท่านั้น
- การดำเนินการที่มีความเสี่ยงสูงต้องพิมพ์ข้อความยืนยันที่กำหนด
- ข้อมูลรับรองของผู้ให้บริการจะไม่ถูกส่งไปยังไคลเอนต์ MCP หรือรีโพซิทอรีนี้
- Skills ของปลั๊กอินและคำอธิบายเครื่องมือ MCP เป็นสิ่งที่เปิดเผยต่อสาธารณะสำหรับการผสานการทำงาน ไม่ใช่ขอบเขตด้านความปลอดภัย โดยมีเฉพาะพฤติกรรมของผลิตภัณฑ์ และไม่มีพรอมต์ระบบของแอปเดสก์ท็อป ข้อมูลผู้ค้า หรือข้อมูลรับรอง
